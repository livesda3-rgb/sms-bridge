# SMS Bridge

Пересылка входящих SMS с домашнего Android-устройства на личный телефон через интернет. Поддержка USB-модема Huawei запланирована как отдельный источник сообщений.

## Текущий статус — Android 0.1 / веб-клиент 0.2

В папке [android](android/) находится диагностический проект Android Studio. Он собран на Mac M2 и установлен на Samsung S23 Ultra с Android 14. Назначение основным SMS-приложением и выдача разрешений выполнены. Проверка приёма SMS и кодов подтверждения с реальной SIM пока ожидается.

Приложение сохраняет новые входящие SMS локально, показывает отправителя, текст и идентификатор подписки SIM. Интернет-пересылка в APK, правила маршрутизации и пароль ещё не реализованы.

В папке [docs](docs/) добавлен веб-клиент: PWA, подписка Web Push, обработчик входящих уведомлений, история, поиск и фильтр SIM. [Настройка GitHub Pages, протокол и ограничения](WEB_CLIENT.md). Клиент готов к интеграции; реальная push-доставка с APK пока не проверена. Девять автоматических тестов проходят: `node --test tests/*.test.cjs`.

## Сборка

Откройте папку `android` в Android Studio и выполните Gradle Sync, затем Run на подключённом устройстве. JDK 17, SDK 35, минимальная версия Android 10.

Подробности и ограничения: [инструкция](android/README_RU.md).

## Дальнейшая разработка

1. Проверить обычные, длинные SMS, коротких и буквенных отправителей, OTP и получение при заблокированном экране.
2. Подключить APK к протоколу веб-клиента и проверить реальную доставку на Android и iPhone.
3. Добавить очередь отправки и повторные попытки на Android.
4. Добавить до пяти сохранённых профилей SIM и маршрутизацию к получателям. Для неизвестной SIM пересылка выключена.
5. Добавить пароль входа, защиту ключей и проверки фоновой работы.
6. Добавить источник сообщений через USB-модем после определения его модели.

План размещения: веб-клиент на GitHub Pages, установочные APK в Releases. На данный момент сайт и APK в Releases не опубликованы.
