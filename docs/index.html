Подключение

01

Откройте сайт по HTTPS. На iPhone: Safari → Поделиться → На экран «Домой», затем откройте значок приложения. На Android: меню браузера → Установить приложение.

Нужен APK 0.4. Покажите QR на Android и сканируйте его здесь. Затем покажите ответный QR камере Android и назначьте получателя для SIM. Код действует 15 минут.

Наведите камеру на QR домашнего телефона.

Вставить данные вручную

Приватный ключ остаётся на домашнем телефоне. Номер телефона получателя для интернет-доставки не нужен.

3. Покажите этот QR домашнему Android

На Android 0.4 нажмите «Сканировать ответный QR» и держите камеру на коде, пока не прочитаются все части. Затем подтвердите получателя и настройте SIM.

Передать данные вручную

Содержит параметры доставки. Передавайте только владельцу домашнего устройства.

Локальная проверка не проверяет доставку через интернет.
