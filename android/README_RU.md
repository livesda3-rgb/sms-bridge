# SMS Bridge 0.1 — диагностический проект

Это исходный проект Android Studio, НЕ готовый APK. Java 17, AGP 8.7.3, Gradle 8.9, compileSdk 35, minSdk 29.
Выбран Java без внешних библиотек для минимального диагностического проекта; полноценную версию можно развивать на Kotlin.

## Запуск на Mac M2
1. Распакуйте ZIP, Android Studio → Open → папка SmsBridge (где settings.gradle).
2. Дождитесь Gradle Sync. Если предлагается установить Android SDK Platform 35 / Build Tools — установите через SDK Manager.
3. Если возникает ошибка Java/Gradle: Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK → Download JDK → 17 (ARM64 на Mac M2).
4. Выберите подключённый Samsung и нажмите Run ▶. Не создавайте новый проект и не обновляйте версии Gradle/AGP по предложению IDE во время этого теста.
5. В приложении нажмите «Назначить основным», подтвердите, затем «Выдать разрешения».
6. Сверьте показанные SIM и subId. Пришлите обычное SMS, затем запросите код нужного вам сервиса. Повторите с заблокированным экраном.
7. В приложении должны появиться полный текст, исходный отправитель, время получения, subId и результат сохранения в системной SMS-базе.
8. После теста кнопкой «Вернуть прежнее SMS-приложение» откройте настройки приложений по умолчанию и выберите прежние Сообщения.

## Границы версии
- Принимает только новые SMS_DELIVER, когда является основным SMS-клиентом. Старую переписку не импортирует.
- Длинные SMS объединяются из частей системного события.
- Входящие SMS записываются в системную базу, а диагностическая копия — в приватную базу приложения (100 последних событий; экран показывает 30).
- Если subId неизвестен, он остаётся -1: приложение не угадывает SIM.
- Не отправляет SMS, не загружает MMS, не реализует быстрый ответ на звонок. Не является полноценной заменой повседневного SMS-клиента.
- Нет сетевого разрешения, пушей, правил, пароля, автостарта до первого разблокирования. Это намеренный тест приёма перед следующим этапом.
- Уведомление скрывает текст; полный текст доступен внутри приложения. Диагностическая база защищена стандартной песочницей Android, отдельного шифрования/пароля пока нет. Резервное копирование приложения отключено.
- Не отправляйте реальные коды и полные SMS в чат; для отчёта достаточно времени, типа отправителя, subId и результата.

## Проверка
Проверить на двух SIM, буквенном и коротком отправителе, кириллице и длинном сообщении, при заблокированном экране.
Время в журнале — время обработки приложением, а не гарантированное время доставки сети.
На этапе выдачи проекта реальный Samsung и полноценная Gradle-сборка в среде автора не проверены; фактическая установка выполняется на вашем Mac.
