# Android 0.3 — SMS Bridge

Откройте эту папку в Android Studio на Mac (JDK 17 / SDK 35), Sync → Run. Для обновления существующей 0.1 используйте прежний debug-ключ Android Studio: он находится в профиле пользователя Mac и не входит в репозиторий. Не удаляйте приложение перед обновлением.

Назначьте SMS Bridge основным SMS-приложением и выдайте разрешения. Для надёжной работы домашнего устройства проверьте разрешённую фоновую работу в настройках батареи. После перезагрузки один раз разблокируйте Android. Входящие MMS и отправка исходящих SMS пока не реализованы.

## Привязка

«Показать QR подключения» → в установленной PWA «Сканировать QR с Android» → разрешить уведомления → в APK «Сканировать ответный QR с iPhone» → проверить имя и подтвердить. Приглашение одноразовое (256 бит), действует 15 минут. Затем отдельно назначьте получателя каждой SIM. Новые SIM не пересылают SMS автоматически. Один получатель может быть выбран для нескольких SIM.

«Отправить тестовый push» проверяет весь интернет-маршрут без SMS. Статус «Принято push-сервисом» не означает, что клиент его уже получил. При 401/403/404/410 получатель отключается и нужна повторная привязка. При временных сетевых ошибках и 429/5xx сообщения остаются в очереди с повторами. Старше 24 часов удаляются; лимит очереди — 1000 push-частей.

## Реализация

- SMS_DELIVER → системная SMS-база и диагностическая база → правило SIM → SQLite-очередь → JobScheduler → HTTPS Web Push.
- Отдельный VAPID P-256 ключ Android Keystore на установку, ECDH + HKDF-SHA256 + AES128GCM (RFC 8291), ES256 VAPID (RFC 8292). Новая случайная ECDH-пара на каждый запрос.
- Подписки импортируются только с HTTPS endpoint Apple/Google/Mozilla; редиректы запрещены. Приглашение проверяется по хешу, одноразово расходуется только после явного подтверждения.
- Отзыв удаляет получателя, очередь и правила. Переназначение SIM не отправляет старую очередь новому получателю. Уже выполняющийся или отправленный HTTP-запрос отозвать нельзя.
- При разрешённом ICCID профиль использует SHA-256 ICCID. Если Android его скрывает — subId. Слот и название оператора не являются идентификаторами. Автоматическое узнавание возвращённой SIM не гарантируется.
- JobScheduler восстанавливает задания после перезагрузки; дополнительное периодическое задание восстанавливает обработку очереди. Doze, системные квоты, принудительная остановка и ограничения производителя могут задерживать отправку. Постоянного foreground service нет.
- История Android и очередь хранятся в sandbox приложения без отдельного шифрования базы. VAPID private key не экспортируется. Backup выключен; окно APK защищено FLAG_SECURE. Собственного пароля у APK пока нет.

На 0.1 подтверждён OTP Yandex с буквенным отправителем на Samsung S23 Ultra / Android 14, включая свёрнутое приложение и выключенный экран. 0.2 установлен пользователем; QR и интернет-пересылку 0.3 ещё нужно проверить на устройствах.

Сканер ZXing Android Embedded 4.3.0 (Apache-2.0) встроен в APK: отдельное приложение не требуется. Камера запрашивается только при сканировании, снимки не сохраняются. AndroidX включён для зависимости. Gradle 8.9: используйте JDK 17 или 21, не 25.
